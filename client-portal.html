Frequently Asked Questions

Information about what is — and is not — working today

Is this a real customer account?

No. This is a design demonstration with illustrative sample documents and requests. There is no production authentication or real customer database.

Can I upload tax records through the portal?

Not yet. The file picker only displays a file name in your current browser session. It does not transmit or save the file. Please do not use personal or financial documents for this preview.

Can I send a message to my accountant?

The demo request form saves a temporary draft locally for review, without sending it to the firm. To contact the team now, use the email or contact link provided here.

Will the portal work on a mobile phone?

Yes. The portal design is responsive and can be previewed on desktop, tablet and mobile. Production security and real workflow integrations are separate future steps.
